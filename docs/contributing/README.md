# Contributing

For people who work on ai-operator itself: the design and its internals,
developing and checking the web UI, how releases are built, and the sandbox
test plan that runs the operator against a real GitLab project. These pages
may name source files and functions, and they have no length cap.

## Pages

In reading order:

1. **[Design](design.md)**: architecture, CRDs, pod topology, token economy
   and security.
2. **[Releasing](releasing.md)**: calendar versions, who decides a release,
   the release pipelines, published images and chart.
3. **[Sandbox test plan](sandbox-test-plan.md)**: an end-to-end run with a
   real GitLab project and the real agent CLIs.
